# 任务目录

每个正式开发任务建议创建：

```text
docs/tasks/TASK-XXXX.md
```

---

## 命名

```text
TASK-0001-project-init.md
TASK-0002-user-auth.md
TASK-0003-interview-session.md
```

---

## 任务生命周期

```text
TODO
↓
ANALYZING
↓
READY
↓
IMPLEMENTING
↓
VERIFYING
↓
DONE
```

失败或阻塞：

```text
BLOCKED
```

---

## 每个任务必须包含

```text
背景
目标
范围
非目标
约束
验收标准
测试
风险
```
