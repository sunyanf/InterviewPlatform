# AI Agent 执行说明

当人工给出一个开发任务时，Agent 默认按：

```text
1. 识别任务类型
2. 读取规则
3. 加载上下文
4. 搜索现有实现
5. 识别约束
6. 设计方案
7. 实施最小修改
8. 测试
9. Review
10. 更新文档
11. 汇报
```

---

## 2. AI Agent 的默认决策权

### 可以自行决定

- 变量名；
- 函数拆分；
- 私有实现；
- 测试组织方式；
- 非核心代码格式。

### 不应自行决定

- 新产品能力；
- 核心业务规则；
- 核心数据库模型；
- 公共 API 兼容性；
- 服务拆分；
- 核心 Agent 状态模型；
- 安全策略；
- 生产部署策略。

---

## 3. 发现问题时

优先：

```text
修复当前任务直接相关问题
```

对于无关问题：

```text
记录建议
不要顺手修改
```
