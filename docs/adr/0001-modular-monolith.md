# ADR-0001：第一阶段采用 Modular Monolith

## 状态

Accepted

## 背景

项目由个人 / 小团队开发，需求高度变化，核心复杂度来自 AI Agent、RAG、Evaluation，而不是服务数量。

## 决策

第一阶段采用 Modular Monolith。

## 原因

- 开发成本低；
- 调试简单；
- AI Coding 更容易理解上下文；
- 避免 RPC / 服务治理噪音；
- 未来仍可按模块拆分。

## 代价

- 单进程故障影响面更大；
- 模块间隔离主要由代码边界保证。

## 未来拆分条件

出现明确的：

- 性能瓶颈；
- 发布独立性需求；
- 团队边界；
- 故障隔离需求；

再拆服务。
