```text
Task

```

# 2. AI 功能

```text

```

# 3. 提交

# 4. 不接受

- 无测试的核心功能；
- 无来源的考试知识；
- 未验证的 AI 输出；
- 泄露敏感信息的日志；
- 绕过架构规则的“快捷实现”。
