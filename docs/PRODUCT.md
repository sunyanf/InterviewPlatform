# 产品需求文档

## 1. 用户

### 求职用户

希望：

- 上传简历；
- 选择岗位；
- 模拟真实面试；
- 得到专业反馈；
- 找出能力缺口；
- 持续训练。

### 考试用户

希望：

- 练习结构化面试；
- 练习笔试；
- 获取评分；
- 查看训练趋势。

---

# 2. MVP 功能

## 2.1 用户

- 注册
- 登录
- 用户资料

## 2.2 简历

- PDF / DOCX 上传
- 解析
- 结构化
- 技能抽取

## 2.3 岗位

- 岗位分类
- 岗位详情
- JD 上传
- 岗位要求结构化

## 2.4 面试

- 创建面试
- 设置难度
- 设置时长
- AI 出题
- 动态追问
- 结束面试

## 2.5 回答

MVP：

- 文字

V1：

- 音频

V2：

- 图片 / 视频

## 2.6 报告

- 总分
- 能力维度
- 优点
- 不足
- 知识缺口
- 学习建议
- 下一次训练建议

---

# 3. 非目标

MVP 不做：

- 数字人
- 实时视频表情评估
- 支付
- 社区
- 企业版
- 大规模岗位爬虫
- 自研基础模型

---

# 4. 核心指标

### 产品
